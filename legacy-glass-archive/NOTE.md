# Legacy — The Glass Archive skin system (retired 2026-07-01)

This folder holds the **previous** house style: the dark "Glass Archive" multi-skin
system (Observatory / Sentinel / Daybreak / Military / Angelic / Demonic / Nature /
Chic / Pro) with its `sky`/`hero` canvas engines and per-skin cursor FX.

It was **replaced** as Jordan's house style by **Daybreak Editorial** (warm editorial
light, Goldenrod accent, Space Grotesk + JetBrains Mono, depth cards). The new single
source of truth lives at the **root** of this repo (`tokens.css`, `style.css`,
`effects.js`, `index.html`, `README.md`).

Kept for reference and recovery only — do not build new work from here. Full history is
also preserved in git.
